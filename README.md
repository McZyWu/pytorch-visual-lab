# TorchScope

一个面向中文学习者的 PyTorch 可视化函数图谱。它把 PyTorch 官方文档全量 API 索引，与高频接口的概念、调用方法、公式、变量含义、最小代码示例和可交互 Tensor 实验放在同一个界面中。

## 功能

- 从 PyTorch 2.13 stable 官方文档 inventory 自动生成 9,066 个 API 条目
- 覆盖 21 个模块分组，支持名称、用途、模块和接口类型筛选
- 每个条目都提供中文解析、核心关系式、精确官方签名、变量地图、场景 Example 和输入输出实验
- 数学、梯度、损失、卷积、归约、形状和线代算子展示专属输入、中间算式与最终数值
- 构造器、属性、设备和配置接口展示真实的返回对象或状态变化，不使用统一生命周期占位输出
- 另有 15 个精选函数的图形化 Tensor 实验，覆盖张量、形状、数学运算、神经网络和损失函数
- 中文概念解释、公式与逐变量解析
- 可编辑 JSON Tensor 输入，实时查看输出和 shape 变化
- 函数搜索、分类筛选和本地学习进度
- 响应式布局，支持桌面和移动设备

## 本地运行

```bash
npm install
npm run dev
```

打开 `http://localhost:3000`。

## 构建

```bash
npm run build
```

## 更新官方文档索引

下载目标 PyTorch 文档版本的 `objects.inv` 到项目根目录，然后运行：

```bash
npm run docs:generate
```

> 实验台在浏览器中模拟所展示函数的数值行为，用于教学与直觉验证；生产训练代码仍应使用正式 PyTorch 运行时。
