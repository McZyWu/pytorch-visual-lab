# TorchScope

一个面向中文学习者的 PyTorch 可视化函数图谱。它把 PyTorch 官方文档全量 API 索引，与高频接口的概念、调用方法、公式、变量含义、最小代码示例和可交互 Tensor 实验放在同一个界面中。

## 功能

- 从 PyTorch 2.13 stable 官方文档 inventory 自动生成 9,066 个 API 条目
- 覆盖 21 个一级模块，并把全部 API 继续划入卷积、归一化、注意力、稀疏格式、分布式通信等二级细分类；支持名称、用途、模块、细分类和接口类型筛选
- 类、函数、方法和其他接口分栏浏览；一级模块与二级分类分成独立横向标签区，详情内容再按介绍、调用、Example、输出和相似方法切成小标签页，减少纵向滚动
- 二级分类提供独立“相似方法对比表”索引，统一说明哪些方法相似、主要区别，以及区别表和模拟实验的直接入口
- 为卷积、池化、激活、损失、矩阵乘法、归约、形状与逐元素运算提供同类算法对照表，清楚列出输入 shape、计算维度、同值计算过程与结果差异
- Conv1d/2d/3d 另有可切换的逐位置滑窗实验：明确区分 1D/2D/3D 空间核、完整通道权重 shape 与对应滑动轴，高亮当前输入窗口与卷积核坐标，并解释 W→H→D 枚举顺序、stride 跨步、padding 虚拟格、输出尺寸和合法输入约束
- 每个条目都提供中文解析、核心关系式、精确官方签名、变量地图、场景 Example 和输入输出实验
- 函数解释统一拆成“具体做什么、逐步怎么算、返回值、副作用、可读示例”；没有独立数学公式的对象或状态接口直接展示处理规则，不放空泛占位公式
- Foreach 批量算子按实际 List[Tensor] 语义讲解并模拟，区分普通版本返回新列表与下划线版本原地修改
- 数学、梯度、损失、卷积、归约、形状和线代算子展示专属输入、中间算式与最终数值
- 所有可计算算子共享交互式 Tensor Flow：一维向量、二维矩阵和三维长方体同步呈现输入、当前计算位置与输出，可逐步或自动播放
- 矩阵乘法高亮参与点积的行与列；多通道卷积和池化高亮当前滑窗；reshape、transpose 等操作直观看到形状重组
- 三维及更高维张量的每层都有独立标签和数值预览，可点击任意层完整展开，不再被相邻层遮挡
- 数学定义参照 PyTorch 官方文档，使用 KaTeX 标准排版，并紧邻解释公式读法、每个符号、张量形状和索引含义
- 可点击打开单个输出位置的计算小窗口：逐项列出输入坐标、权重坐标、数值与乘积，并用同色边框关联回张量中的原始格子
- 构造器、属性、设备和配置接口展示真实的返回对象或状态变化，不使用统一生命周期占位输出
- 另有 15 个精选函数的图形化 Tensor 实验，覆盖张量、形状、数学运算、神经网络和损失函数
- 中文概念解释、公式与逐变量解析
- 可编辑 JSON Tensor 输入，实时查看输出和 shape 变化
- 函数搜索、分类筛选和本地学习进度
- 响应式布局，支持桌面和移动设备

## 本地运行

```bash
npm install
npm run dev
```

打开 `http://localhost:3000`。

## 构建

```bash
npm run build
```

## 更新官方文档索引

下载目标 PyTorch 文档版本的 `objects.inv` 到项目根目录，然后运行：

```bash
npm run docs:generate
```

> 实验台在浏览器中模拟所展示函数的数值行为，用于教学与直觉验证；生产训练代码仍应使用正式 PyTorch 运行时。
